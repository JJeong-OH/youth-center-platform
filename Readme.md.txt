# 청소년 수련관 통합 플랫폼

   청소년들의 성장을 추적하고 관리하는 통합 플랫폼

   ## 🎯 주요 기능
   - 회원 관리 (모바일/키오스크)
   - 프로그램 예약 시스템
   - AI 상담
   - 포트폴리오 자동 생성
   - 설문조사 & 역량 평가

   ## 🛠 기술 스택
   - **Frontend**: Next.js 15, React, TypeScript
   - **Backend**: NestJS, Prisma
   - **Database**: PostgreSQL (Docker)
   - **AI**: Google Gemini API

   ## 📦 설치 및 실행

   ### Backend
```bash
   cd backend
   npm install
   npm run start:dev
